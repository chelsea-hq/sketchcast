## Findings detail

### SEC-005-01 [HIGH, FIXED] Unbounded braces nesting

- **Location:** replacement declared at `package.json:28` and `package.json:36`;
  canonical lock entry at `package-lock.json:669`, Chokidar alias at `:5144`,
  micromatch alias at `:8734`.
- **Surface:** dependency availability and supply chain.
- **Original evidence:** `braces@3.0.3` allowed an 8,003-character pattern with
  4,000 nested braces under its 10,000-character length limit, reaching recursive
  walker stack exhaustion. Parent's regression suite recorded seven failing
  depth checks before replacement, alongside passing ordinary consumer cases.
  The [advisory](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm) had no official
  upstream fixed release available at the recorded intake.
- **Remediation:** direct exact `@dieub/braces-depth-guard@3.0.3-pn.3`, plus
  `overrides.braces = npm:@dieub/braces-depth-guard@3.0.3-pn.3`. Both installed
  Chokidar and micromatch resolve that package, not original braces.
- **Reviewed implementation:** `lib/constants.js` defines depth 100.
  `lib/parse.js:37`, `:148` and `:205` bound length and brace/parenthesis nesting.
  `lib/compile.js:10`, `lib/stringify.js:9` and `lib/expand.js:51` bound recursive
  AST walkers. `lib/utils.js:6` clamps oversized depth options and defaults
  invalid/nonfinite values to the hard limit; `:13` preserves the 10,000-character
  ceiling and rejects numeric NaN. Each processor snapshots its own limit.
  These paths refer to the installed canonical package under
  `node_modules/@dieub/braces-depth-guard/`.
- **Independent proof:** 89 bounded assertions passed: installed consumer
  resolution, depth 100 acceptance and 101 rejection, braces/parentheses/mixed
  nesting, nonfinite/oversized/getter options, length NaN/infinity, normal
  expansion and AST parent-cycle rejection. All seven installed runtime files
  plus `LICENSE` byte-match
  [source commit 305a2e4](https://github.com/dieub/braces-depth-guard/tree/305a2e4bfe324bb53c336c1b03387ee1251c926f).
  Both alias installations also byte-match the canonical runtime and license
  after the frozen install.
- **Provenance:** the dependency reviewer verified downloaded SHA-512, all ten
  published files, registry signatures and Sigstore provenance bound to that
  commit. These are independently attributed results in the linked dependency
  report. The registry maintainer is `dieub`; retained author attribution is
  not a claim of an official upstream release. There are no lifecycle install
  hooks and the existing runtime dependency remains `fill-range: ^7.1.1`.
- **Threat boundary and limits:** Chokidar calls `braces.expand(path)` on strings
  (`node_modules/chokidar/index.js:258`); micromatch uses string patterns
  (`node_modules/micromatch/index.js:426`, `:452`, `:463`). No application use of
  caller-built ASTs was found. Expansion's `queueOwner` at `lib/expand.js:34`
  detects parent cycles but does not cap long acyclic parent chains in arbitrary
  caller-built ASTs. The patch also does not add an expansion-cardinality/AST-width
  cap or remove deliberate `rangeLimit: false` behavior. These are limitations
  of the optional API, not demonstrated new exposure in the observed consumers.
  No universal denial-of-service guarantee is claimed.
- **Maintenance:** this is a recent, single-listed-maintainer fork. Keep its
  exact canonical dependency, override and lock integrity aligned. Continue
  monitoring original braces advisories as well as the fork; an upstream-name
  advisory need not automatically attach to a renamed package. Replace the
  temporary fork when a compatible official fix passes the same contracts.
- **Status:** fixed and fully re-evaluated within this scope. Both full and
  production audit gates now pass without suppression; source/behavior review,
  rather than the clean scanner result alone, supports closure.

### SEC-005-02 [MEDIUM, FIXED] Aggregate embedded-image amplification

- **Location:** `lib/project-file.ts:358`.
- **Surface:** untrusted import / browser availability.
- **Evidence and fix:** the historical report records a valid-CRC synthetic
  100-image payload accepted before remediation, representing 1.6 billion
  pixels. The implementation now counts unique referenced image IDs and rejects
  totals above 40 million pixels or 6 MiB of decoded base64 bytes before saving
  or decoding. Unused attachments remain excluded from output.
- **Status:** fixed and re-evaluated. Relevant source hashes remain unchanged
  from the independent failing-before/passing-after review; current full tests
  pass on the replacement dependency graph. No large browser decode was run.

### SEC-005-03 [MEDIUM, FIXED] Excessive hatched-geometry work

- **Location:** `lib/project-file.ts:239`.
- **Surface:** untrusted import / browser availability.
- **Evidence and fix:** the historical report records a 381-byte giant filled
  rectangle accepted before remediation. Maximum dimensions/actual point extents
  are now 16,384, scene coordinates are bounded to ±100,000, and an aggregate
  20,000 hatch-work estimate accounts for narrow strokes, repeated passes and
  filled-path intersections before preview. This is a conservative work proxy,
  not a universal memory guarantee.
- **Status:** fixed and re-evaluated. All five original geometry regressions
  are retained and pass; ordinary starter/hatched diagrams remain supported.

### SEC-005-04 [LOW, FOLLOW-UP] Conditional KaTeX prototype-pollution gadget

- **Location:** `package-lock.json:8176`; `lib/board-actions.ts:31` and `:93`.
- **Surface:** diagram-renderer dependency.
- **Evidence:** locked KaTeX 0.16.47 remains affected by
  [GHSA-238p-pmpm-9mq7](https://github.com/advisories/GHSA-238p-pmpm-9mq7).
  Both saved audits report four Low package records for this one family:

- **Reachability:** Mermaid conversion is reachable, but this advisory requires

  prerequisite was demonstrated. The installed Mermaid strict configuration,
  math sanitization/final DOMPurify path and project parser's prototype-key
  rejection remain unchanged; these do not prove every possible pollution
  path is absent.
- **Remediation:** track a compatible patched Mermaid/KaTeX graph and verify
  diagram/math behavior. The scanner's proposed editor/converter downgrades
  were not applied.
- **Status:** documented Low follow-up, owner PRD 005, review by 2026-10-22.
