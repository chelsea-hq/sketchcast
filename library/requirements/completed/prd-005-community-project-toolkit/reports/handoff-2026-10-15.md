## What changed

Creators can download an unencrypted `.sketchcast` project and import it as a
separate local project, including the board, supported embedded raster images,
script, aspect ratio, and webcam layout. Recordings and credentials are excluded.
Duplication creates an independent project without cloud identity.

Three original editable examples help creators explain a process, compare two
ideas, or teach a concept. Home now shows actual board previews, search, sort,
import, duplication, and clearer empty states. Project dialogs use native modal
focus behavior. Mobile preparation retains usable project and download controls.

The reload-to-create data-loss defect is fixed. Storage operations wait for
IndexedDB transaction completion, failed autosaves remain visible with recovery
actions, and project transitions share a guard against overlapping operations.

Dependencies received compatible security and maintenance updates. Playwright
now reproduces four Community workflows, and CI runs them against its production
build. Contributor instructions, file-format documentation, changelog, roadmap,
security model, and release checklist reflect the implemented behavior.
